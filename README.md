# 1989 SKO

Dansk prototype-shop kun til Maison Margiela GAT sneakers.

Funktioner:
- Prototypeproduktkatalog uden produktfotos
- Shop med kategorifiltre og søgning
- Produktdetaljer med størrelse og stand
- Session-baseret kurv
- Stripe Checkout endpoint
- Admin-login og Convex hooks fra den tidligere storefront

Start lokalt:

```bash
npm install
npm run dev
```
